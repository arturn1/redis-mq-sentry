# redis-mq-sentry

## Serviços
- frontend-next: Next.js app
- bull-board-app: Backend com Bull-board
- consumer-redis-fast: Consumer Redis (rápido)
- consumer-redis-slow: Consumer Redis (lento)
- consumer-rabbitmq: Consumer RabbitMQ
- redis: Banco de dados Redis
- rabbitmq: Broker RabbitMQ
- sentry: Monitoramento Sentry

## Como rodar

```sh
docker-compose up --build
```
